Works with any OpenAI-compatible endpoint (DeepSeek / OpenAI / Moonshot / DashScope compatible mode / local Ollama). When enabled, the model only rewrites the one-sentence advice and explanation; numbers, ranking and evidence still come from the offline engine. Turn it off to stay fully offline.

The key is stored locally in outputs/agent_ui/settings.json (mode 0600) and is only sent to the endpoint you configure. Environment variables DEEPSEEK_API_KEY / OPENAI_API_KEY / LLM_API_KEY are also supported.
